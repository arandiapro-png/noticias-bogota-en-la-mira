# Noticias Bogotá en la Mira — Entrega 2

Prototipo funcional desarrollado con HTML, CSS y JavaScript.

## Funcionalidades
- Home con noticia principal y noticias destacadas.
- Listado dinámico desde `data/noticias.json`.
- Filtros por categoría y búsqueda.
- Vista de detalle.
- Favoritos con `localStorage`.
- Formulario de contacto con validaciones y mensaje de confirmación.
- Mini CRUD local para crear y eliminar noticias de prueba.
- Diseño responsive.

## Ejecución
Por usar `fetch()` para leer el JSON, se recomienda ejecutar con un servidor local (por ejemplo, Live Server en VS Code) y no abrir `index.html` directamente con `file://`.

## Estructura
- `index.html`
- `noticias.html`
- `detalle.html`
- `favoritos.html`
- `contacto.html`
- `administrar.html`
- `css/styles.css`
- `js/app.js`
- `data/noticias.json`
